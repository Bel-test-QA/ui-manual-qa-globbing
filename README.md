# 🌐 Проект 2: Набор инструментов для ручного тестирования пользовательского интерфейса: Сервис регистрации | Globbing Shopping Solutions

Итоговая аттестационная (проектная) работа по программе повышения квалификации **«Специалист по тестированию программного обеспечения» (TSU)**. 

Проект посвящен комплексному ручному функциональному тестированию сервиса регистрации пользователей для платформы **«Globbing Shopping Solutions»**. Работа успешно выполнена, полностью документирована и защищена в рамках сетевой программы обучения.

---

## 📂 Структура репозитория

```text
├── introduction/           # Шаг 0: Введение, описание объекта тестирования, цели тестрования.
├── checklists/             # Шаг 1: Приложение А — Чек-лист тестирования формы регистрации
├── test-cases/             # Шаг 2: Набор детальных тест-кейсов (UI)
├── bug-reports/            # Шаг 3: Оформленные баг-репорты и Приложение Б (категории дефектов)
├── test-metrics/           # Шаг 4: Приложение В — Тестовые метрики 
├── test-summary/           # Шаг 5: Заключение — Сводный отчет о результатах тестирования (TSR)
├── full-project/           # Итог: Полная версия аттестационной работы от Введения до Приложений
└── project-defense/        # Демо: Видеозапись защиты проекта и официальный сертификат ТГУ
```

---

## 📋 Содержание аттестационной работы

Все артефакты контроля качества и сопутствующие документы извлечены и упакованы в структурированные PDF-файлы для быстрой и удобной навигации:

*   **Введение (`introduction/`):** Описание объекта тестирования, цели тестрования.
*   **Чек-листы (`checklists/`):** *Приложение А* — Высокоуровневый список проверок.
*   **Тест-кейсы (`test-cases/`):**  Позитивные и негативные сценарии проверок для ручного функционального и нефункционального тестирования.
*   **Баг-репорты (`bug-reports/`):** Официально оформленные дефекты с шагами воспроизведения и приоритетами, а также *Приложение Б* с градацией серьезности и жизненным циклом (статусами) багов.
*   **Тестовые метрики (`test-metrics/`):** *Приложение В* — Базовые метрики, вычислительные метрики, метрика эффективности тестового набора.
*   **Сводный отчет (`test-summary/`):** *Заключение* — Финальный отчет (Test Summary Report), включающий описание процесса тестирования, список выполненных проверок, общие выводы по качеству объекта тестирования.
*   **Полный проект (`full-project/`):** Единый «целиковый» документ аттестационной работы, объединяющий все разделы и приложения.

## 🛠️ Технологический стек и инструменты

*   **Тест-дизайн & Документирование:** Чек-листы, Тест-кейсы, Баг-репорты, Сводные отчеты (TSR / TSR-метрики).
*   **Виды тестирования:** Функциональное тестирование, UI/UX тестирование, Регрессионное, Позитивное/Негативное тестирование.
*   **Инструменты фиксации:** Скринкасты (.mp4), Графические скриншоты дефектов.
